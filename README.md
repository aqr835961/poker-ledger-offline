# 德州撲克離線記帳 App — 一般記帳模式

本專案僅包含「一般記帳模式」，**不含人頭賞金模式**。

## 安裝

1. 將此資料夾內所有檔案及 `icons` 資料夾原樣部署到 HTTPS 靜態網站（例如 GitHub Pages）。
2. 用 iPhone Safari 開啟部署網址，選「分享」→「加入主畫面」。
3. 首次連網開啟後，待資源快取完成，再切換飛航模式測試離線啟動。
4. 所有帳務只存在裝置的 IndexedDB，請定期使用「匯出 JSON 備份」。

注意：直接從 iPhone「檔案」App 開啟 `index.html` 無法保證 IndexedDB 與 Service Worker 正常運作；需要 HTTPS 部署才能安裝離線 PWA。

## 固定規則

- 牌局 2～12 人，可自訂名稱與順序；每人 3,000，總額為人數×3,000；盲注 10/20。
- 三區塊同時輸入：小遊戲、現金桌籌碼、額外獎勵。
- 小遊戲：莊家倍率、閒家下注 0～2,000、個人倍率、贏／輸／不下注，莊家反向結算。
- 額外獎勵每筆正負合計為 0，直接併入當局現金桌盈虧。
- 結算固定三區塊，現金換算為總籌碼盈虧除以 2，若有小數，按絕對值無條件進位至整數元。
- 局間小遊戲獨立輸入與結算，不重複計入。
- 已結算資料不可在 App 中直接修改；未結算草稿會保留在本機。

## 檔案

- `index.html` 主頁
- `app.js` 完整本機計算、表單、結算與 IndexedDB
- `styles.css` 手機介面
- `manifest.webmanifest` 安裝設定
- `service-worker.js` 離線資源快取
- `icons/` App 圖示

## 第一版限制

- 需要自行部署 HTTPS 網址；ZIP 檔案本身不是可直接安裝的 iOS IPA。
- App 尚未經 iPhone Safari 實機完整驗收，正式帳務前請先進行測試。
- 目前僅匯出／匯入 JSON；匯入會覆蓋本機所有牌局，請先備份。
- 資料僅儲存本機，不提供多人即時同步。
