# 德州撲克離線記帳 App V2 — 一般記帳模式

## 功能
- 只提供一般記帳模式，沒有賞金模式。
- 2–12 人牌局，自訂玩家名稱、順序、參與人數與每人起始籌碼。
- 原有三區塊輸入與三區塊正式結算、局間小遊戲、零和驗證、現金換算絕對值進位規則保持不變。
- 牌局主畫面「修改牌局」：修改名稱、玩家名稱、顯示順序、現役人數、未來局數起始籌碼；指定歷史局數起始籌碼時，若該局結尾籌碼不符合新總額會拒絕修改。可改由「歷史紀錄」在同一筆修改中同步修正起始與結尾籌碼。
- 結算頁「修改本局紀錄」及「結束整場牌局」；結束後可重新開啟及修改歷史資料。
- 每局保留玩家 ID 與起始籌碼快照；新局保存完整小遊戲與額外獎勵輸入。修改整筆替換並保留修改前後稽核快照，不會重複入帳。
- 舊 V1 資料會自動轉換成 V2 結構，保留原有玩家身分及盈虧。**V1 沒有保存小遊戲原始下注、倍率、結果，無法還原這些欄位。** 舊版已結算局數可修正起始/結尾籌碼，保留原小遊戲與額外獎勵結果；舊版局間小遊戲僅可查看。不要刪除 V1 原始備份。
- JSON 匯出與匯入，支援 V1/V2 格式。

## 更新 iPhone 上的 GitHub Pages
1. **先在舊 App 匯出 JSON 備份，保存到 iPhone「檔案」。**
2. 解壓本 ZIP，進入 `poker-ledger-pwa` 資料夾。
3. 在原有 GitHub 儲存庫 `aqr835961/poker-ledger-offline` 的根目錄更新 `app.js`、`service-worker.js`、`README.md`。`index.html`、`styles.css`、`manifest.webmanifest` 與 `icons` 均沿用原版，不需重建 Repository。也可以將 ZIP 內全部檔案覆蓋原檔。
4. GitHub Pages 發布成功後，**先連網開啟網站並重新整理，再關閉並重新開啟主畫面 App**。Service Worker 快取名稱已升級至 `poker-ledger-v2-20261018`。
5. 確認「修改牌局」及「結束整場牌局」按鈕出現，再測試飛航模式。

## 帳務安全
- IndexedDB 資料僅存在當前裝置的網站儲存區。刪除 App、清除網站資料或 iOS 回收儲存空間可能遺失帳務。
- GitHub Pages 僅存放程式碼，不儲存使用者記帳資料。
- 任何大量修改前請先匯出備份。
- 修改前後的稽核快照儲存在 JSON `audit` 欄位；本版尚未提供圖形化逐筆還原介面，必要時可透過備份還原。
- 更新完成前請勿刪除舊版備份。
